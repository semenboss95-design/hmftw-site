# hmftw-site

Static site generated by the hmftw project from its own database: public facts about Copart lots, collected automatically; no lot photos, no descriptions, no sale prices. Generation photos come from Wikimedia Commons under free licenses, with attribution on each page. Independent non-commercial project, not affiliated with Copart, Inc.; the data may be inaccurate or out of date. Branch `main` is overwritten on every publish; the builder code is not here.
