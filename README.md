# hmftw-site

Статический сайт, сгенерированный проектом hmftw из собственной базы; данные — публичные
факты о лотах Copart, собранные автоматически; фотографий и описаний источника здесь нет.

Независимый некоммерческий проект, не связанный с Copart, Inc.: публикуются только
публичные факты о лотах, собранные автоматически, без фотографий, описаний и цен продажи;
данные могут быть неточными и устаревшими.

Ветка `main` перезаписывается целиком при каждой публикации (история обрезается — условие
«репозиторий < 1 ГБ»). Кода сборщика здесь нет, он в приватном репозитории.
